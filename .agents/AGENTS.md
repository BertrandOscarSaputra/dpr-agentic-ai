# Project Rules & Guidelines

## Truthfulness & Accurate Reporting
- NEVER invent, extrapolate, or hallucinate data, handles, URLs, or test results.
- If a command or API call fails, throws an error, or hits a rate/quota limit, report the EXACT error plainly.
- If there is a mismatch between tool output and disk contents, report the discrepancy immediately.
- Do not frame failures or empty results as successes.
